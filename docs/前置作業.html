Loop Engineering · 連線前置作業

第一次使用：先讓你的裝置連得上

Loop Engineering 跑在辦公室那台 DGX Spark 上，沒有對網際網路開放。所以在看任何操作說明之前，你的筆電或手機要先加入我們的私有網路（Tailscale）。全部大約十分鐘，一台裝置只要做一次。

這份文件是獨立檔案，離線也看得到，可以直接轉寄。

你會拿到什麼

① Tailscale 邀請信寄到你的公司信箱，主旨大致是「You've been invited to join a Tailscale network」。點信裡的連結就能加入。
② 站台網址形如 https://<機器名>.<你的網路>.ts.net，由管理者另外傳給你。這個網址只有在 Tailscale 連線時才打得開。
③ 一次性 token附在網址後面（?token=…）。點過一次，瀏覽器就記住了，之後直接開網址即可。
token 請當成密碼拿到網址的人就等於拿到這台機器上的資料。請不要貼到群組、不要轉寄給名單外的人；需要給新同事時，請管理者另外發給他。

為什麼要裝 Tailscale？

這台機器只聽自己的本機位址，公司內網和外網都連不到它。Tailscale 會在你的裝置和那台 Spark 之間拉一條加密的點對點通道，等於把你的筆電「放進」它旁邊。裝好之後不分地點：公司、家裡、出差都一樣能連。

四個步驟

1

接受邀請，建立 Tailscale 帳號

打開邀請信，按邀請連結，用公司的 Google 帳號登入（不必另外設密碼）。看到網路名稱出現在畫面上就完成了。

2

在裝置上安裝 Tailscale 並登入

Windows到 tailscale.com/download 下載安裝，登入後右下角工作列會有圖示，狀態要是 Connected。
macOSApp Store 搜尋 Tailscale 安裝，或同一個下載頁。登入後右上角選單列會有圖示。
iPhone／iPadApp Store 安裝 Tailscale，登入後把開關打開，狀態列會出現 VPN 字樣。
AndroidPlay 商店安裝 Tailscale，登入後打開開關。

登入時務必選和邀請信同一個帳號，否則會加進別的網路，看不到這台機器。

3

用管理者給你的完整網址打開站台

在瀏覽器貼上帶 ?token=… 的完整網址。看到左上角「Loop Engineering · CF-AOI 維運大腦」就成功了。之後把不含 token 的網址加到書籤即可，瀏覽器已經記住憑證。

建議用 Chrome 或 Edge。手機也可以，版面會自動收成單欄。

4

填一次你的名字

左上角 ☰ 打開「對話紀錄」，在下方填你的名字後按「記住」。這只是把每個人的對話分開放，方便各自找回自己問過的東西。

這不是權限控管知道網址與 token 的人都看得到這台機器上的全部資料，包括別人的對話。真正的界線是「誰拿得到網址與 token」。

連好之後，從這裡開始

站台右上角有一顆「？」，裡面就是全部的說明：

  • 3 分鐘上手：八張動畫卡，看完就知道每個按鈕在做什麼。
  • 完整操作說明：每個功能的細節、設定與疑難排解。
  • 連線前置作業：就是這份，可以轉寄給還沒連上的同事。

連不上的時候，照這張表檢查

網址完全打不開先看 Tailscale 的狀態是不是 Connected。手機容易在省電模式被關掉，打開開關再試一次。
出現「請提供 token」或空白頁你開的是不含 token 的網址，而瀏覽器換過（或清過資料）。用管理者給你的完整網址重開一次。
連得上，但看不到任何資料token 過期或被換掉了，請管理者重發。
頁面上方寫「模型啟動中」或「模型未載入」那台機器正在換模型或剛重開，通常幾分鐘內會變回「模型就緒」，等一下再問。
回答很慢模型在本機跑，有人同時在問或正在跑評比就會變慢。右側「機台」面板可以看目前的速度。
用手機看版面很擠左上 ☰ 和右上 ▤ 可以把兩側收起來，只留對話。

幾件先知道會比較好的事

  • 回答是在公司這台機器上算出來的，不會送到雲端，也不花公司的訂閱額度。只有你明確按「請雲端複核」或跑模型評比時才會用到雲端。
  • 它知道的是 CF-AOI 的程式碼與文件。問它公司外的事情，除非你打開「上網／工具」，否則它只能靠既有知識回答。
  • 它不會去動機台。調參那些是建議，要不要套用由工程師決定。
  • 看板上的任務是真的會被執行的。如果你只是想記一件事，用「待辦」就好，不要按排入佇列。
  • 終端機、切換模型這類按鈕只有工程師身分看得到，看不到是正常的。
需要協助連線、token、帳號的問題，找這台機器的管理者（呂侑儒）。功能怎麼用的問題，直接在站台右上角「？」→「3 分鐘上手」通常就有答案。
